TaskManagementSystem
This project was created to strengthen my understanding of object-oriented programming and data persistence in C#. The application allows users to create tasks, track completion status, and save/load task data using JSON files.

Concepts Practiced
Classes and Objects
Constructors
Properties
Methods
Object State Management
Collection Management
JSON Serialization
JSON Deserialization
File I/O
Console Applications
System Design
TaskItem ↓ TaskManager ↓ JSON File

The TaskItem class stores information about individual tasks, while the TaskManager is responsible for managing task collections and saving/loading data.

Features
Create Tasks
Track Task Completion
Mark Tasks as Completed
Display Task Information
Save Tasks to JSON
Load Tasks from JSON
Persist Data Between Application Sessions
